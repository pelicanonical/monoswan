<Code code={`monoswan init [path]`} lang="sh" />

`path` defaults to the current directory.

The command creates `monoswan.config.ts` with an empty `lib` variant and the default `enforceVariants()` and `sortPackageJson()` rules. It creates the target directory when needed and does not overwrite an existing configuration.
