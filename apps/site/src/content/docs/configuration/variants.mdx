## Validation behavior

- Objects are checked recursively. Extra keys are allowed.
- Arrays and primitive values must match exactly.
- Configured files must exist.
- Text files must match exactly, including whitespace and trailing newlines.
- JSON-backed files accept JSONC comments and trailing commas.

## Composing variants

Packages can select multiple variants. monoswan merges them in the listed order. JSON objects are deeply merged; for text files, the last defined value wins. Unknown variant names produce an `INVALID_VARIANTS` error.

Variant content is only checked when a rule does so. Add `enforceVariants()` to validate the fields shown above.

See the [variant and file reference](/docs/configuration/variant-files/) for field types, path
resolution, missing and invalid files, and initialization behavior.
