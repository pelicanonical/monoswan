## Install

Install monoswan at the workspace root.

<Code
	code={`# pnpm\npnpm add -D -w monoswan

# npm\nnpm install -D monoswan

# yarn\nyarn add -D -W monoswan

# bun\nbun add -D monoswan`}

lang="sh"
/>

The workspace root must contain `pnpm-workspace.yaml` or a `workspaces` declaration in
`package.json`.

Workspace discovery supports pnpm workspace files, npm and Bun workspace arrays, and both Yarn
workspace forms, including modern Yarn Plug'n'Play installations. monoswan reads the declaration
directly and does not invoke the package manager during discovery.

## Lint the workspace

Run the script with your package manager:

<Code
	code={`# pnpm\npnpm monoswan

# npm\nnpm run monoswan

# yarn\nyarn monoswan

# bun\nbun run monoswan`}

lang="sh"
/>

Run the corresponding `monoswan:fix` script to apply available fixes before reporting remaining
issues.
